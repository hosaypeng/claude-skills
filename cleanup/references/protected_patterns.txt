# Protected paths — /cleanup never trashes anything matching these.
#
# One shell glob per line, matched against the FULL expanded path. `~` expands
# to $HOME. `#` starts a comment. Bracket classes work: *[Ss]lack* matches both
# casings.
#
# This is a hard stop: unlike the whitelist it cannot be overridden per run,
# and dry-run reports matches as SKIPPED (protected). Categories follow Mole's
# app_protection_data.sh, trimmed to what matters on this machine. Add a
# pattern here when an app keeps auth state, keys, or irreplaceable data in a
# directory that looks like a cache.
#
# Scope deliberately: system mode cleans Electron `Cache`/`Code Cache` leaves
# under ~/Library/Application Support for idle apps (Slack, Discord, Zoom), so
# messaging patterns are limited to ~/Library/Caches and container roots where
# auth tokens actually live. ~/.codex and ~/.cursor are on the regenerable
# dotdir list in cleanup_system.sh and are intentionally not protected.
